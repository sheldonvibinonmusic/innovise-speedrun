# Demonstration Datasets

This directory holds sample financial filings and demonstration data for testing the application:

1. **`demo_company_10k.pdf`**: Sample 10-K filing for automated ingestion testing.
2. **`planted_discrepancy_sample.pdf`**: Synthetic disclosure with known discrepancies between MD&A and financial statements for inconsistency testing.

*Note: Large PDF files should not be committed to Git. Placeholders and synthetic minimal fixtures are managed in `tests/fixtures/`.*
